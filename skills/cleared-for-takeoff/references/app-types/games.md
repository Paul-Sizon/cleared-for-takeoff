# Games

- [ ] Loot boxes and random items: disclose the odds before purchase (3.1.1). Scanner: `payments/lootbox-odds`.
- [ ] Virtual currency: never expires. Bought via IAP only. No cashing out (unless real-money gaming is licensed, see finance doc).
- [ ] Game streaming / emulators: allowed (4.7). Each streamed game needs its own product-page metadata if listed. Mini-apps and plug-ins follow the 4.7 rules (HTML5 content, no native code downloads, age-appropriate, IAP for digital goods).
- [ ] Game Center: don't use it for spam or unsolicited messages (4.5.4 / Oct 2026 wording).
- [ ] Rewarded ads: fine for in-game bonuses, but not to unlock core features in place of IAP, and not "watch ads for a review".
- [ ] Age rating: violence, simulated gambling (casino-style), and the UGC/chat in multiplayer.
- [ ] Multiplayer chat counts as UGC (1.2): report, block and filter.
- [ ] Controller support claims must be real. Don't require hardware the reviewer may not have without a fallback.
- [ ] Clones of popular games (names, art, mechanics marketed as the original) are rejected under 4.1 / 5.2.
